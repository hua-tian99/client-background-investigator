客户背景调查系统 Windows 便携版
================================

适用系统
--------
Windows 10/11 x64，Chrome 或 Edge 浏览器。

首次使用
--------
1. 将整个 ZIP 解压到本机文件夹，不要直接在压缩包内运行。
2. 双击“启动背调系统.bat”。
3. 等待浏览器自动打开 http://localhost:3000。
4. 在系统配置面板中填写本机使用的 DeepSeek API Key 和飞书配置。
5. 导入本机负责的 Excel 后开始背调。

重要说明
--------
- 本软件已内置 Node.js，不需要安装 Node.js、npm 或其他开发环境。
- 每台电脑的配置保存在该电脑浏览器的 localStorage 中，不会随 ZIP 分发。
- ZIP 中不包含 DeepSeek Key、飞书 App Secret、客户资料或历史结果。
- 软件可以离线启动，但 AI 背调和飞书同步需要互联网连接。
- 批量背调期间请保持黑色终端窗口开启；关闭窗口会停止服务。
- 不要在批量运行期间刷新浏览器，未导出的当前会话结果可能丢失。

功能二提示
----------
请配置包含 table=tbl... 和 view=vew... 的完整飞书视图链接。系统会仅读取该视图中的记录，并使用“记录 ID + 订单号”进行双重校验。

升级
----
1. 完成并导出旧版本中尚未保存的结果。
2. 关闭旧版本终端窗口。
3. 将新版 ZIP 解压到一个新文件夹后运行。
4. 浏览器配置通常仍会保留，因为访问地址仍是 localhost:3000；如未保留，请重新填写。

常见问题
--------
1. 提示端口 3000 已占用：说明本机已有服务运行，脚本会打开现有页面。若它不是本系统，请先关闭占用端口的软件。
2. 浏览器未自动打开：手工访问 http://localhost:3000。
3. Windows 安全提示：确认 ZIP 来自项目维护人员并核对随包提供的 SHA-256 文件。
4. 页面翻译导致异常：关闭 Chrome/Edge 对该页面的自动翻译，然后按 Ctrl+F5。
